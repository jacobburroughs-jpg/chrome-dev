# Chrome DevTools Practice

A hands-on practice project for preparing for a Junior Developer Chrome DevTools practical assessment.

## Purpose

This project provides a simple web application that can be used to practice debugging and development workflows using **Google Chrome DevTools**.

The goal is to build familiarity with the tools and techniques required to inspect, modify, debug, and troubleshoot a web application.

## Technologies

- HTML
- CSS
- JavaScript
- Google Chrome DevTools

## DevTools Skills

The project is designed to practice:

### DOM & HTML
- Inspecting HTML elements
- Identifying tags, classes, IDs, and parent elements
- Editing HTML through DevTools
- Adding and modifying attributes
- Manipulating the DOM with JavaScript
- Creating DOM elements with JavaScript

### CSS & Styles
- Inspecting CSS rules
- Viewing computed styles
- Modifying CSS through DevTools
- Understanding the CSS cascade and specificity
- Identifying overridden CSS rules
- Inspecting the CSS box model

### JavaScript
- Executing JavaScript in the Console
- Selecting DOM elements with `querySelector()`
- Modifying DOM properties
- Creating and inspecting JavaScript objects
- Adding event listeners
- Using `console.table()`

### Network
- Inspecting HTTP requests
- Identifying request methods and status codes
- Inspecting request payloads
- Examining API responses
- Understanding common HTTP status codes
- Troubleshooting failed or unexpected requests

### Sources & Debugger
- Locating JavaScript source files
- Searching source code
- Setting breakpoints
- Inspecting variables and scope
- Stepping through JavaScript execution
- Understanding the call stack
- Modifying runtime state

### Debugging
The final stage of the project focuses on diagnosing a realistic UI bug and determining whether the problem originates from:

- The DOM
- JavaScript
- An API response
- Incorrect property access
- Another underlying cause

## Getting Started

Clone the repository:

```bash
git clone git@github.com:jacobburroughs-jpg/chrome-dev.git
```

Navigate into the project:

```bash
cd chrome-dev
```

Open `index.html` in Google Chrome.

Open Chrome DevTools with:

```text
Right Click → Inspect
```

or:

```text
⌘ + Option + I
```
